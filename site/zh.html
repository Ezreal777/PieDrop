从选中到投递

四步，一气呵成。

为「刚在 Finder 里看到、马上想让 AI 处理」的时刻设计，中间不需要碰键盘打字。

01 / FINDER

选中文件

在 Finder 选中一个或多个文件：代码、设计稿、日志、数据文件都行。

02 / ⌃⌥F

唤起圆盘

全局快捷键随时唤起光环面板。默认 ⌃⌥F，可在菜单栏自定义。

03 / HOVER

预览会话

扇区按 CLI 着色，悬停预览右侧卡片：任务缩略、所属终端、未发送草稿。

04 / CLICK

路径落位

点击扇区，路径在目标会话输入框的光标处插入——不自动发送，是否回车由你决定。

为多会话并行设计

细节都为「选得准」。

同时开着多个 agent 会话是常态。PieDrop 的一切设计，都是为了让你在一秒内把文件交给正确的那个。

01 / 光环模式

左圆右方，磨砂玻璃

左侧是按 CLI 着色的扇区圆盘，右侧是当前会话的结构化卡片：任务缩略、终端、未发送草稿。

02 / 菜单模式

紧凑列表样式

偏好列表就切换到菜单模式，hover 展开任务缩略与草稿详情，空间紧张时更省事。

03 / 草稿感知

正等你输入的那个，置顶

有未发送输入的会话在列表中置顶、在圆盘中获得更大的扇区角度，多会话并行时一眼锁定。

04 / 会话发现

进程 × TTY 精确配对

ps 扫描 agent 进程，与终端窗口按 TTY 配对。空闲的 zsh / bash / fish 终端也能投。

05 / 双通道注入

iTerm2 免聚焦直写

iTerm2 直接 write text；Terminal.app 走剪贴板 + 模拟 ⌘V。两条通道按终端自动选择。

06 / 本地与可自定义

数据不出机器

无网络访问、无数据收集、无后台服务。快捷键、开机自启、面板样式都在菜单栏图标里调整。

Homebrew 安装

已配好第三方 tap，一条命令安装：

brew install --cask ezreal777/tap/pie-drop
# 首次安装会提示信任第三方 tap，按提示确认即可

首次打开，需要放行一次

项目用自建证书签名（没有付费开发者账号），macOS 会拦第一次。放行之后重新编译、升级都不会再拦。

  1. 双击 PieDrop，提示「无法验证开发者」时点「完成」
  2. 打开 系统设置 → 隐私与安全性，点底部「PieDrop 已被阻止」旁的「仍要打开」
  3. 按启动提示授权 辅助功能 与 自动化（Finder / 终端）权限，之后即可正常使用
  • 辅助功能向 Terminal.app 模拟 ⌘V 粘贴路径
  • 自动化（Finder）读取当前选中的文件
  • 自动化（Terminal · iTerm2）定位会话窗口、写入输入框

App 完全本地运行：不上网、不收集数据；草稿预览只读取终端屏幕尾部最后一条未发送输入。

使用前的小提示

几个实用问题。

路径会被自动发送吗？

不会。路径只插入到目标会话输入框的光标处，你可以继续补充一句话再回车，也可以直接删掉。空闲终端里则直接停在命令行上等你编辑。

为什么需要辅助功能和自动化权限？

Terminal.app 通道靠模拟 ⌘V 粘贴（辅助功能）；读取 Finder 选区、定位会话窗口需要自动化授权（Finder / Terminal / iTerm2）。iTerm2 通道则通过其接口直接写入，不依赖模拟按键。

同时开着很多会话，怎么选得准？

扇区按 CLI 着色区分；悬停任意扇区，右侧卡片显示该会话的任务缩略、所属终端和未发送草稿。有草稿的会话还会置顶并获得更大的扇区，通常那就是你正想继续的那个。

会收集数据吗？

完全本地运行：无网络访问、无数据收集、无后台服务。草稿预览只读取终端屏幕尾部最后一条未发送输入，用于会话识别与排序。
